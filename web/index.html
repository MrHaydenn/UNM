Using Add Empty Tunnel

  1. In WireGuard, choose Add Tunnel → Add Empty Tunnel. Give it a name such as UNM-PC.
  2. Keep its [Interface] and PrivateKey lines on your PC. Copy only the Public key shown above the editor.
  3. In UNM, choose Add host → Create a new WireGuard peer. Enter a host name, leave the address blank, and paste that public key into Host public key.
  4. Click Add host. UNM configures the VPS peer and shows your host settings. Click Copy settings for empty tunnel.
  5. Paste those settings on a new line below your existing PrivateKey line. Keep just one [Interface] section. Click Save, then Activate.
  6. Click Refresh in UNM and look for a recent handshake. Allow the service you want to forward through Windows Firewall.

Alternative: import a generated file

Leave Host public key blank when adding the peer. UNM generates a complete configuration. Save it immediately, then use Add Tunnel → Import tunnel(s) from file in WireGuard and activate it. You do not need an empty tunnel for this method.

Never share a PrivateKey or a screenshot containing one. If a key was shared, create a fresh empty tunnel before registering its public key.
